# Keyboard shortcuts

App shortcuts never take keys a terminal program needs, such as Ctrl-C, Ctrl-D or Esc; those go to the terminal. {{mac}}On macOS, Control with a digit selects terminal tabs.{{/mac}}{{other}}So shortcuts that would be Ctrl with a letter the shell uses, like Ctrl+L or Ctrl+W, are Ctrl+Shift with that letter, and **Check again** is F5. In terminals, Ctrl+Shift+C and Ctrl+Shift+V copy and paste. If a key does nothing, your input method may take it: see [Keys that do nothing](linux#keys-that-do-nothing).{{/other}}
